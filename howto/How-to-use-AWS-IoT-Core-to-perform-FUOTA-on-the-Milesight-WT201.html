How to use AWS IoT Core to perform FUOTA on the Milesight WT201

How to use AWS IoT Core to perform FUOTA on the Milesight WT201

Version Update Time Description Author
1.0 July 1, 2025 Initial version Charles
1.1 Feb 28, 2025 Added a reminder to enable the FUOTA function when registering the sensor, as well as the FUOTA parameters for the WT201. Charles

Description

Milesight WT201 supports FUOTA firmware upgrades via the AWS IoT Core platform. This article will guide you on how to perform FUOTA operations for the WT201 on AWS IoT Core.

Requirement

Milesight WT201 V1: Firmware version v1.4 and above

Milesight WT201 V2

Prerequisites

Please make sure that your WT201 has been registered to AWS IoT Core and that the FUOTA configuration has been enabled. Also, ensure that both the GenAppKey and Confirm GenAppKey are set to the same value as the AppKey.

Configuration

Step 1: After your Milesight WT201 and LoRaWAN gateway are both connected to AWS IoT Core, please create an S3 bucket on the AWS platform to store the .PATCH file required for FUOTA.

Step 2: Click on the S3 bucket you created, and then upload the .PATCH file to this S3 bucket.

Step 3: Copy the device ID of the WT201 that you want to perform the FUOTA operation on.

Step 4: Create a multicast group.

Enter the multicast group you have created and ensure that your WT201 is in the "Multicast setup ready" state.You can only start the FUOTA process when the multicast devices are in the "ready" state; otherwise, the FUOTA will fail.

Step 5: Create a FUOTA task.

Please ensure that the Advanced Transmission Parameters used for this FUOTA task are consistent with those shown in the diagram below.

Step 6: Add multicast group to the FUOTA task.

Step 7: Schedule the FUOTA process.

Before FUOTA start time arrives, the FUOTA task will be in the "FUOTA session waiting" state.

When the FUOTA start time arrives, the status of the FUOTA task will change to "in FUOTA session" and device status will change to “initial”.

When the FUOTA task is completed, the status of the FUOTA task will display "FUOTA DONE" and the device status will display "Successful". When the FUOTA task is completed, your WT201 will need about 10 minutes to finish the upgrade and it will reboot automatically after finishing the upgrading. Therefore, after the FUOTA task is done, please wait for 10 minutes before using the Milesight ToolBox to check the WT201’s firmware version.
