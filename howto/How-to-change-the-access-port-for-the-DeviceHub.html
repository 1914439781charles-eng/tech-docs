Description

This article will describe how to change the access port for the DeviceHub interface, so that customers can configure the port used to access DeviceHub according to different security policies.

Requirement

Devicehub

Configuration

Step 1: Locate the www.conf file and use the command "vim www.conf" to edit the file.

Step 2: Please refer to the image below to change the TCP port, remove the redirect code, and copy the necessary content as needed.

Step 3: After completing the configuration changes, please save the contents of the www.conf file and restart the DeviceHub service.

Step 4: Aceess the web interface of the devicehub v1.
