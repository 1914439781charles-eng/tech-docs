How to Change the Node-RED Admin User Login Password on the Gateway

How to Change the Node-RED Admin User Login Password on the Gateway

Version Update Time Description Author
1.0 Mar 3, 2026 Initial version Aurora

Description

This article will describe how to change the Node-RED admin user login password on the gateway. It aims to address situations where you need to update the login password or when you are unable to log in due to a forgotten or incorrect password.

Requirement

Milesight gateway(UG65/UG56/UG67)

Problem

Configuration

Step 1: Enable SSH access on the gateway and log in to the gateway backend as the root user.

Step 2: Check the Node-RED configuration file and confirm that the password is configured in the file in a hashed format.

When you enter the password on the Node-RED login page of the gateway, the system will hash the entered password and compare it with the password hash stored in the settings.js file. If the hashes do not match, access will be denied.

Step 3: Use the command ”node-red admin hash-pw” to generate a new password hash.

Step 4: Edit the /etc/node_red/settings.js file and update the value of the password field with the newly generated hash.

Step 5: Restart the node-red service.

Step 6: Use the new password to login the gateway.
