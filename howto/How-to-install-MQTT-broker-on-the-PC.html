How to install MQTT broker on the PC

How to install the MQTT broker on the PC

Version Update Time Description Author
1.0 Jun. 13, 2026 Initial version Luis

Description

Under typical MQTT networking scenarios, the gateway’s built-in NS acts as the publisher, while the MQTT client serves as the subscriber. To facilitate testing and troubleshooting, this article provides guidance on how to deploy an MQTT broker on a PC to function as the MQTT server.

Requirement

MQTT Broker: mosquitto

Configuration

Step 1: Download the mosquitto software

Download | Eclipse Mosquitto

Stpe 2: Install the mossquitto

Stpe 3: Modify the mosquitto.config file.

Listener

Set the listening port to 1883 (default), which must be aligned with the MQTT client configuration.

Allow_anonymous

Change it to allow_anonymous false. This means anonymous login is not allowed. If anonymous login is permitted, then change it to allow_anonymous true

Password_file

Change it to password_file pwfile.example. This sets the location of the account password file, which is pwfile.examplein the root directory by default.

Stpe 4: Creat the account

Open Windows PowerShell as an administrator

Go to the software installation directory and run the command.

./mosquitto_passwd -c pwfile.example admin

Enter the password and confirm it.

Stpe 5: Start the MQTT broker

Open the Mosquitto installation folder, right‑click in the blank area, and select "Open in Terminal".

Run Mosquitto using mosquitto.confas the configuration file and enable verbose logging.

./mosquitto -c ./mosquitto.conf -v

After pressing Enter, we can see from the terminal feedback that mosquitto version 2.0.14 is running. The service has opened listening sockets on port 1883 for both IPv6 and IPv4. The MQTT broker (local server) has started successfully!
