How to collect logs when the gateway's cellular network is disconnected

How to collect logs when the gateway's cellular network is disconnected

Version Update Time Description Author
1.0 Jun. 13, 2026 Initial version Luis

Description

Cellular network issues on the gateway usually require two types of logs for troubleshooting:

Gateway debug log

Gateway QXDM log

The following describes how to collect these logs:

Configuration

Step 1: Set the log file mode is “Debug” mode

Step 2: Set the log file mode is “Debug” mode

Step 3: Download the putty or other SSH tool to login the gateway backend

Download PuTTY: latest release (0.84)

Step 3: Login the gateway backend

Enable the SSH/Telnet service and check the servie port number on the web GUI. If you access the gateway via remote network, ensure the remote access options are enabled.

 Open Putty.exe software, select corresponding connection type as SSH or Telnet, then type in the device IP address (or domain name) and port, then click Open. If you connect PC to device LAN port or Wi-Fi, the Host Name is 192.168.1.1 by default. 

Login the gateway with the account root/LoRaWAN@2018, and send the command below(red background field):

root@GATEWAY:~# vtysh

*** TERMINFO:/etc/terminfo TERM:xterm *****

-- model:UG65,sn:6221E2465759,hwver:0130 partnumber:L04EU-868M-EA--

-------------------------------------------------------------------------

Product Model : UG65

Firmware Version : 60.0.0.49

-------------------------------------------------------------------------

GATEWAY> en

GATEWAY# conf t

GATEWAY(config)# cellular send at at+cgfcont]

cellular.c:5609 cellular_send_at: Send AT at+cgfcont?

GATEWAY(config)#

Step 4:Download the degbut log and qxdm log after 10 mins

Debug log

QXDM log

Stop and download the qxdmlog

Please send the debug log and QXDM log to the technical support team for analysis.
