Description

The built-in Network Server (NS) in Milesight gateways supports the FUOTA feature, which enables you to upgrade the firmware of sensors added to the gateway’s built-in NS. This article will guide you on how to implement the FUOTA feature on Milesight gateways.

Requirement

  • Milesight UG6x gateways with firmware version 60.0.0.46 or above

  • Milesight UG56 gateways with firmware version 56.0.0.6 or above

  • Sensors that support the standard LoRaWAN FUOTA protocol

Configuration

Step 1: FUOTA for LoRaWAN sensors using the built-in network server on Milesight gateways requires a .PATCH file or a .BIN file Please contact Milesight technical support and inform them of your device’s current firmware version as well as the firmware version you wish to upgrade to. The Milesight technical support team will provide you with the appropriate .PATCH file or .BIN file based on this information. In this article, I will use the WT201 with firmware version v1.5-a2 for testing, and upgrade its firmware to v1.6-t1 using the FUOTA feature of the built-in network server on the Milesight gateway.

Step 2: Please refer to this article(How to Connect LoRaWAN Nodes to Milesight Gateway : IoT Support) to connect your LoRaWAN sensor to the built-in network server of the Milesight gateway.

Step 3: FUOTA Task Configuration.

① Click the “Add” button to create a new FUOTA task.

②Task Settings

• Task Name: Fill in the task name,repeatable data.

• Start Time: Task start time, default one hour later.

• Description: Task description, edit without limitations.

③ Firmware setting

• Firmware selection with a new .PATCH or .BIN file uploaded, Differential upgrade firmware package for select sensors.

• Configuration of fragment downlink (stay default).

Fragment Size: Usually, it is recommended to keep the default setting. In LoRaWAN environments with less interference, the fragment size can be increased to 128 bytes to improve transmission efficiency. In more interference-prone environments, the fragment size can be reduced to 64 bytes to minimize the impact of losing a single fragment on the overall transmission.

Fragment Interval: Usually, it is recommended to keep the default setting. In LoRaWAN environments with less interference, the interval can be reduced to 2–3 seconds to shorten transmission time. In environments with more interference, it can be increased to 7–10 seconds to give the device more time for processing.

Redundancy percent: Usually, it is recommended to keep the default setting. In LoRaWAN environments with less interference, it can be reduced to 10–20% since the network is stable and the packet loss rate is low. In environments with more interference, it can be increased to 40–50% to improve the success rate of transmission.

• After the firmware selection or uploaded, there will be device listed and you can select the devices you want to upgrade.

④ Multicast Setting

• DR and frequency of fragment downlink in multi-cast (stay default)

Step 4: Task Creation finished

After the task creation, it will be listed on the FUOTA and status will be Pending.

Step 5: Task Start

When the task start time arrives, the status will be waiting.

When the device is ready, the FUOTA task will start, and update status will be "Executing".

Packets will show downlink packet with size 91, which is 88+3 as configured and The whole upgrade process takes about 15-20 minutes.

Step 6: FUOTA Task Finished

When it finished, status will be Finished.

If success, status will be 'Updated successful

Note: After the gateway shows“Upgrade complete”,it takes time for the sensors to be upgraded.

For the gateway, the upgradeis successful when the nodereceives astatus response from the gateway, but in reality, the sensor may not have completed the upgradeyet.

In fact, at this time, the sensor may not have completed theupgrade, generally need to wait 10 15 minutes after the completion of the gateway transmission before the node will complete the installation of the upgrade package.

If failed, update status will be failed, you can hover your mouse to see the reason.
