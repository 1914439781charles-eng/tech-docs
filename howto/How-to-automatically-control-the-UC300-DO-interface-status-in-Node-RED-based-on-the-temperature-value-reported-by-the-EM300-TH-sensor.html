How to automatically control the UC300 DO interface status in Node-RED based on the temperature value reported by the EM300-TH sensor

How to automatically control the UC300 DO interface status in Node-RED based on the temperature value reported by the EM300-TH sensor

Version Update Time Description Author
1.0 June 30, 2026 Initial version Aurora

Description

This article will describe how to automatically control the UC300 DO interface status in Node-RED based on the temperature value reported by the EM300-TH sensor

Requirement

Milesight gateway(UG65 gateway as example)

Milesight sensor(EM300-TH as example)

To achieve this requirement in Node-RED, meet the following two conditions:

Obtain the gateway API token. The token value is used to call the gateway API and send downlink commands to control the UC300 DO status.

2.Obtain the uplink data reported by the EM300-TH and filter out the temperature value.

Workflow:

Step 1: Find the password to get the Token, please refer to the gateway’s HTTP API document.

Step2：Obtain the data reported by the EM300-TH and use a decoder to parse the encrypted data.

If you would like to learn how to use the decoder on the Node-red, please refer to the article below:

https://support.milesight-iot.com/support/solutions/articles/73000535734-how-to-use-decoder-on-node-red

Step3: Obtain the temperature value and set a conditional check for the temperature. When the specified condition is met, output different payload commands.

Step4: Construct the HTTP API downlink format and call the API to send the downlink command.

When the temperature value exceeds 23°C, Node-Red will automatically invoke the gateway HTTP API to send a downlink command to turn on the DO of the UC300.
