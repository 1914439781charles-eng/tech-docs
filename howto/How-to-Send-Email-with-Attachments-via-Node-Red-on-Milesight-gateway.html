How to Send Email with Attachments via Node-Red on Milesight gateway

How to Send Email with Attachments via Node-Red on Milesight gateway

Version Update Time Description Author
1.0 Feb 27, 2026 Initial version Charles

Description

This article will guide you on how to send emails with attachments using a Node-Red program on a Milesight gateway.

Requirement

Milesight Gateway: UG56/UG65/UG67

SMTP server and email account

Configuration

Step 1: Launch Node-RED and Import Flow Example

Go to App > Node-RED page to enable Node-RED program and wait for a while to load the program, click Launch button to start Node-RED web GUI.

Log in the Node-RED web GUI. The account information is the same as gateway web GUI.

Step 2: Node-RED Configuration

Flow structure:

Function description for nodes in the node-red flow:

Inject 1: This is a button that is triggered by a right-click to send.

Function 1: This is a node used to construct the content of the email.

email: This is a node used to configure SMTP server information and recipient details.

Step 3: Deploy and Check Result

Click this icon() to download the email node in Node-RED and then upload the tgz file to your Node-RED program.

Click Import to import the node-red flow example by pasting the content or import the json format file.

Double-click the Function 1 node and modify the content of the function node according to your email content, as shown in the figure below.

Double-click the email node, then fill in the corresponding SMTP server information and recipient email address.

5.Click Deploy.

Then when you click the inject node, the Node-RED program will send an email with an attachment to the recipient's mailbox
