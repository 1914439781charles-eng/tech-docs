How to use Python to monitor LoRaWAN packets received by the UG65 gateway

How to use Python to observe the LoRaWAN data packets received by the UG65 gateway

Version Update Time Description Author
1.0 Sept 30th, 2025 Initial version Charles

Description

Currently, the Milesight UR35 does not support sending the DI status to an HTTP server via HTTP directly. However, you can achieve this functionality using Python.

Requirement

Milesight UR35

mSD card/SSD module

Milesight Router Python SDK

Configuration

Step 1: Enter the configuration page of the UR35 and enable the DI function.

Step 2: Please refer to this document to install python SDK: https://support.milesight-iot.com/support/solutions/articles/73000514211-how-to-install-python-sdk-and-read-log

Step 3: Download the attached Python APP and unzip it. Find the main.py file and modify the following parameters.

Step 4: Import the modified Python APP and enable AppManager.

Step 5: Go to APP -> Python -> Python, click View and enter Supervisor page, the default username and password is: pyapp/py123456app.

Step 6: According to the above configuration, I received DI port status notifications from the UR35 on my HTTP server, where the number 1 indicates that the current DI port is at a high level, and the number 0 indicates that the current DI port is at a low level.
