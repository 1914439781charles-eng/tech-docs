Description

This article will describe how to integrate Milesight Gateway to Thingsboard via MQTT.

Requirement

  • Milesight Gateway: UG56, UG65, UG67, UG63 (embedded network server version), UG8x
  • ThingsBoard Account:ThingsBoard Cloud or install your own platform instance

Configuration

Step1: Add Milesight sensor to your Milesight gateway.

Step2: Log in your ThingsBoard account and go to Entities > Devices page to add a Milesight gateway device.

Step3: Customize the device name and enable Whether it is a gateway or not option. If you already created device profile, you can also select corresponding profile. Click Add to save the settings.

Note: click Next: Credentials if you need to customize the client ID and user credentials.

Step4: After device created, select MQTT and Windows option, then copy the command to get MQTT connection information.

In this example, the command is

mosquitto_pub -d -q 1 -h demo.thingsboard.io -p 1883 -t v1/devices/me/telemetry -u "lmcnby8ehhf5etrfgj85" -m "{temperature:25}"

We can get these information from above command:

Broker address: demo.thingsboard.io

Broker port: 1883

Access token: lmcnby8ehhf5etrfgj85

Topic: v1/devices/me/telemetry

Step5: Enable the Node-Red feature on your Milesight gateway and import the relevant JSON(📎 Download flows.json) file.

Step6: Double-click the two nodes shown in the diagram below, and enter the Broker address and Access Token from point 4 above into the Server-side and Username fields, respectively.

The node shown in the figure below is used to filter sensor data based on the Device EUI of the sensor device, to prevent unnecessary sensor data from being reported to ThingsBoard.

Step7: Since data displayed on ThingsBoard needs to be in JSON format, please refer to this article(https://support.milesight-iot.com/support/solutions/articles/73000535734-how-to-use-decoder-on-node-red) to add a decoder for your sensor device.

Step8: Afterwards, you will be able to see the data reported by the sensor on the ThingsBoard platform.

Step 9: To control Milesight sensors via RPC on ThingsBoard, please define RPC controls on the ThingsBoard platform.

In addition to using the aforementioned buttons to send RPC commands, we can also define related buttons according to our needs, as shown in the figure below.

①For the Slider button, when you slide the button, it will send a JSON object {"action":2} to the MQTT client on Node-Red.

②For the switch control, when the button is in the ON state, it will send a JSON object {"params": true} to the MQTT client on Node-Red. When the button is in the OFF state, it will send a JSON object {"params": false} to the MQTT client on Node-Red.

③For the Knob control, when you rotate the knob to a certain value, the MQTT client on Node-Red will receive a JSON object containing that value.

④For the round control, I have written a logic function. When I turn on this button, it will send a JSON object containing the value 1 to the MQTT client on Node-Red. When I turn off this button, it will send a JSON object containing the value 2 to the MQTT client on Node-Red.

Step10: Define a JSON-formatted data payload that will be sent to Node-Red on the gateway when you click this RPC control. This way, you can perform corresponding sensor node control in Node-Red based on the received data content.

Step11: When you click this RPC button on ThingsBoard, Node-Red on the Milesight gateway will receive the data {"action":1}, as shown in the diagram below.

Step12: Finally, you can click the RPC button on ThingsBoard to control the sensors connected to the Milesight gateway.
