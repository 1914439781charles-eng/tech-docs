Description

This Node-RED example provides the solution on how to send custom commands from a TCP server to a sensor, enabling the sensor to successfully execute the command.

Requirement

  • Milesight Gateway: UG56/UG65/UG67

Configuration

Step 1: Launch Node-RED and Import Flow Example

  1. Go to App > Node-RED page to enable Node-RED program and wait for a while to load the program, click Launch button to start Node-RED web GUI.

  2. Log in the Node-RED web GUI. The account information is the same as gateway web GUI.

  3. Click Import to import the node-red flow example by pasting the content or import the json format file.

https://resource.milesight-iot.com/Support/Walden/tcp-downlink-flows.json

Node description.

Node 1: Obtain the token for UG65 in order to call the HTTP API.

Node 2: Send the ff01ff hex command to see if the gateway can receive and execute it.

Node 3：Use the tcp in node to connect and receive commands from the TCP server.

Node 4: Determine the target of the command using devEUI and convert the command sent by the TCP server into a hex command that the sensor can execute.

Node 4：Select the port for sending the command, which needs to be consistent with the port configured when adding the sensor to the UG65.

Step 3: Deploy and Check Result

  1. Click Deploy to save all node-red configurations.

  2. Use the NetAssist tool to act as a TCP server for testing and send commands to the sensor.

    https://resource.milesight-iot.com/Support/Walden/NetAssist_v4.3.25.exe

    The gateway receives the command and successfully forwards it to the sensor for execution.

    The sensor restarts and rejoins the network.
