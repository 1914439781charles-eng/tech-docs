Description:

This article will use Milesight UG56 as an example to illustrate how to achieve the following seven functionalities using Node-RED by calling HTTP APIs.

①Batch export all devices of the built-in NS in the gateway.

②Batch export all custom payload codecs of the gateway.

③Batch import custom payload codecs into the gateway.

④Batch export all applications of the gateway.

⑤Batch import all applications of the gateway.

⑥Batch export profiles of the gateway.

⑦Batch import profiles of the gateway.

Configuration:

①Please import the relevant node flow diagram into your Node-RED software on the gateway. As shown in the following image. You can click on this icon(📎 Download flows (BULK).json) to download the node flow file(JSON file).

②Please click on two locations in the node flow diagram to obtain the HTTP API token, as shown in the following image. You can copy the token. (This token has an expiration time, usually after 24 hours.)

Finally, paste this HTTP API token into the locations shown in the diagram below.

③Batch import custom payload codecs into the gateway.

You can use the exported CSV table from the second point above as a template and name this file as im_codecs.csv, as shown in the following figure.

Afterwards, you can use SFTP to transfer the im_codecs.csv file and place it under the /tmp directory of the UG56 gateway, as shown in the following figure.

Afterwards, when you click on the button as shown in the diagram below on the Node-RED of the gateway, you will see that your custom payload codecs have been imported into the gateway.
