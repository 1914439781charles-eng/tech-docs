Description

This Node-Red setup allows you to output the pulse values read by the Milesight EM300-DI to a third-party pulse counter via the UC300, making it easy for you to observe pulses generated by devices like water meters or electricity meters on the third-party pulse counter.

Requirement

  • Milesight Gateway: UG56/UG65/UG67

  • Pulse Reading Sensor：Milesight EM300-DI

  • Pulse Analog Output Sensor: Milesight UC300

Configuration

Step 1: Launch Node-RED and Import Flow Example

  1. Go to App > Node-RED page to enable Node-RED program and wait for a while to load the program, click Launch button to start Node-RED web GUI.

  2. Log in the Node-RED web GUI. The account information is the same as gateway web GUI.

  3. Click Import to import the node-red flow example by pasting the content or import the json format file.

Node description:

LoRa Input : Receive data from all built-in NS sensors.

EM300-DI: Filter the sensor data from the EM300-DI from the built-in NS according to the Device EUI. Therefore, before using this FLOW, double-click the node and fill in the Device EUI for the EM300-DI you are using.

Function 1:This node is used to decode the data from EM300-DI.

Function 37 and function 41: The two nodes are used together and generally do not require configuration changes. Their function is to open the DO1 port of the UC300 for a certain amount of time and then close it every time the EM300-DI reads 1000 pulses, so as to simulate the output of a pulse.

LoRa Output: This node is used to send a command with the content of 11111 to the UC300. Please fill in the Device EUI of your UC300 in this node. Connect your pulse counter to the DO1 interface of the Milesight UC300, then use the Milesight ToolBox to configure rules for the UC300 (as shown below). The UC300 DO1 port should be open for longer than the minimum pulse width that can be detected by this third party pulse counter.
